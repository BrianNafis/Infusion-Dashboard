Web Dashboard – IV Infusion Anomaly Detection System

Dashboard real-time berbasis web untuk monitoring terapi infus intravena (IV). Sistem ini merupakan bagian implementasi dari jurnal yang dipublikasikan di JUTIF (Jurnal Teknik Informatika), yang mengusulkan deteksi anomali cost-effective menggunakan hybrid deep learning pada sensor IoT.

Fitur Utama:

Visualisasi Real-time: Menampilkan data volume cairan (ml), flow rate (tetes/menit), dan estimasi waktu habis.

Alert Terintegrasi: Notifikasi visual (warna) dan log untuk 5 jenis anomali (Over-infusion, Occlusion, Infiltration, Air Bubble, Empty Bag).

Multi-Pasien: Tampilan ringkasan untuk beberapa bed/ruangan.

Integrasi API: Mengambil data anomali dari Firebase/Backend yang terhubung dengan edge device (ESP32).
